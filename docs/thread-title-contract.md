# Thread title contract

Codex Workbench uses the native Codex 0.146.0 thread name as its first choice,
keeps a deterministic local fallback, and gives an explicit manual title lasting
priority. It does not create a hidden turn, enable tools, or broaden access merely
to produce a cosmetic title.

The deterministic fake-Codex matrix covers German and English multi-part work,
a synthetic workspace-path case, a long initial objective, and a later turn that
changes the focus. It verifies native priority, refresh through `thread/read`,
stable persistence/reconciliation, and the absence of a visible title turn. The
matrix contains no real prompt or filesystem path.

Codex 0.146.0 has native title updates and `thread/name/set`, but no documented,
tool-free title-regeneration request. Native semantic quality therefore remains a
product boundary: Workbench cannot guarantee that every native name summarizes
the whole objective, preserves language, or changes after a later turn. The UI
labels the read-only action “Titelstatus anzeigen …”, explains the boundary, and
keeps the manual title workflow available. No replacement AI or fake primary
action is used.
